# 美漫大世界 · 远程脚本仓库

角色卡《美漫大世界》的手机面板远程托管仓库。卡内只带加载器（引擎尾段）：版本指针（tag 固定起步）→ jsDelivr 三域备胎 → 12s 超时闸刀 → eval。

## 目录

- `dist/phone_panel.js` — 悬浮手机面板（一期三应用：状态总览／四维加点／设置——解析设置＋模式开关＋事件管理；二期追加联系人／聊天）

## 版本

- 卡内加载器 `REF` 常量固定 tag（如 `v0.1.0`）；热更新走 tag 递进或后续接入指针服务
- 指针键值只允许干净字符（`[\w.\-]`），防路径注入
- 本地开发：卡内加载器认 `window.__MM_DEV_BASE`（仅 127.0.0.1/localhost 生效），指向本仓库本地检出根即可直拉 `dist/`，免推 GitHub 调试

## 发版流程

1. 改 `dist/phone_panel.js`
2. 提交并打 tag（`git tag v0.x.y && git push origin v0.x.y`）
3. 需要玩家吃到新版时：改卡内加载器 `REF` 指向新 tag → build → 发卡（或接入指针服务后免发卡）

## 纪律

- 手机面板＝第二作用域：DOM 注入顶层文档，根节点带 `mm-scope` 类，动作全走引擎 `data-mm-a` 委托——手机本体不复制任何引擎逻辑
- 手机自有动作一律 `data-ph-a` 前缀（引擎对未知 `data-mm-a` 会报错）
- 手机数据面＝`__mmPhone桥`（引擎加载器导出：读玩家状态／四维池），二期聊天生成器沿用同一桥扩展
